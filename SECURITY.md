# Security Policy

## Reporting a vulnerability

Please do not publish an actively exploitable vulnerability before a fix is
available. Open a private security advisory through the repository's GitHub
**Security** tab and include reproduction steps, affected versions, and the
expected impact.

For ordinary crashes, compatibility problems, or out-of-memory errors, use a
normal GitHub issue instead.

## Scope

This project does not download models, expose a network service, or execute
workflow-provided shell commands. Security issues in ComfyUI, ComfyUI-GGUF,
PyTorch, or model-hosting services should also be reported to their respective
maintainers.
